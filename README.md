# Expense Tracker

## Project Overview
Expense Tracker is a simple command-line application developed using Python.

## Features
- Add new expenses
- View all expenses
- Calculate total expenses
- Validate user input
- Handle errors
- Save expenses in a JSON file

## Technologies Used
- Python
- JSON
- VS Code
- GitHub

## How to Run
1. Install Python 3.
2. Open the terminal.
3. Run: python3 expense_tracker.py
